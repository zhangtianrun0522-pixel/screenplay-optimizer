# 劣质钩子示例：信息性悬念（错误示范）

## 剧本片段（BL短剧 第3集结尾）
顾炎拉住陆沉："别走！那份机密文件到底被你藏哪了？"
陆沉冷笑："等你查出来，你早就完了。"
说完摔门而出。顾炎立刻拿起手机："喂，帮我查陆沉的底细，越细越好！"

## 诊断分析
- **悬念类型**：信息性悬念（降级）
- **降级原因**：强行将情感冲突降格为俗套商战悬疑。观众对"文件在哪"毫无共鸣，完全剥离了BL受众最看重的情感拉扯。靠生硬的"查底细"制造悬念，缺乏人物内心撕裂感，导致留白干瘪，观众没有点下一集的情绪冲动。
- **修改方向**：删去文件、查底细等外部情节，将悬念落点改回人物关系。用"口是心非"的肢体细节（如掰开手、隐忍落泪）替代生硬对话，制造"他到底还爱不爱我"的情感悬念。
