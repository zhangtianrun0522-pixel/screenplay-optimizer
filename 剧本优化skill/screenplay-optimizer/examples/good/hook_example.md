# 优秀钩子示例：情感性悬念

## 剧本片段（BL短剧 第3集结尾）
顾炎指尖堪堪擦过陆沉衣角："别走……"他眼眶发红，死死盯着对方，"你明明说过不会丢下我。"
陆沉僵住，垂眸掩饰情绪，一点点掰开顾炎的手："那是从前了。"
门关上，顾炎滑坐在地。而门外的陆沉，抬手死死捂住颤抖的唇。

## 分析说明
- **悬念类型**：情感性悬念
- **打分**：95/100
- **依据**：此钩子核心非"陆沉为何离开"（信息悬念），而是"相爱却互相折磨"的极致拉扯。动作（掰开手/门外捂嘴）与台词（那是从前）形成强烈内外反差，精准击中受众虐心爽点。观众急于看第4集，是渴求见证这份隐忍的爱何时爆发，情感驱动力远超剧情推力，留白极具张力。
