# Hook Patterns 钩子系统规则

## 1. 情感性悬念 vs 信息性悬念判断标准

- **检查动作**：
  1. 定位每集最后一段剧本。
  2. 判定悬念驱动源：是否依赖角色尚未说出口/未承认/未行动的情感状态？
  3. 若属纯信息性悬念（如"他到底是谁"/"幕后黑手是谁"），执行【降级标记】。
  4. 优化指令：强制改写为情感动机驱动（将"等待真相揭晓"替换为"角色面对真相的崩溃/隐忍/抉择"）。

## 2. 每集结尾钩子强度检查

- **检查动作**：
  1. 读完每集结尾段，执行核心自测："如果我现在停下不看，我会因为什么情感原因无法放下？"
  2. 评估自测答案的驱动力来源。
  3. 若答案为"想知道信息"（好奇心驱动），而非"替角色着急/心疼/愤怒"（共情驱动），执行【钩子强度不足标记】。

## 3. 跨集钩子链检查

- **检查动作**：
  1. 提取并列出全剧所有集的结尾钩子类型（情感性/信息性/反转类等）。
  2. 顺位比对相邻两集的钩子类型。
  3. 若存在连续两集钩子类型相同（如连续两集均为信息悬念抛出），执行【钩子单调标记】。
  4. 优化指令：强制变更其中一集的钩子类型，形成情绪落差（如：信息悬念后接情感打脸，情感悬念后接信息反转）。

## 4. 情欲张力的接近节奏模式库（Pattern Library）

- **最优状态**：以下三种模式需在不同层级交叉推进
  - 物理距离接近被打断（Physical Approach Interrupted）
  - 情感表白被咽回（Emotional Confession Swallowed）
  - 秘密即将揭露被转移（Secret Revelation Deflected）

- **检查动作**：
  1. 检索全剧，标记三种模式的出现位置与频次。
  2. 排查单一模式的连续出现情况。
  3. 若某一模式连续出现超过两次，且在此期间其他模式缺席，执行【接近节奏单一化标记】。
  4. 优化指令：插入缺席的模式，或重构当前场景的阻断方式。

## 5. 钩子密度检查

- **检查动作**：
  1. 逐集盘点悬念点，区分"集内小钩子"（场景切点/局部冲突升级）与"集尾大钩子"。
  2. 统计单集有效钩子总数 = 集内小钩子数 + 集尾大钩子数。
  3. 若单集有效钩子数量 < 2，执行【该集钩子密度不足标记】。
  4. 优化指令：在场景中段或3/4处强加一个微反转或新冲突变量。
