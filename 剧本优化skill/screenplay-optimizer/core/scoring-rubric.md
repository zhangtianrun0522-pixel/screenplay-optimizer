# 短剧剧本评分量表 (Scoring Rubric)

## 维度一：钩子系统 (Hook System) - 25分

**检查动作：逐集标记结尾悬念类型（情感性/信息性），统计跨集钩子类型数量。**

- **25分**：每集结尾均为情感性悬念，且跨集钩子类型多样（≥3种，如：误会型、掉马型、生死型等）
- **20分**：大部分为情感性悬念（占比≥80%），偶有信息性悬念，钩子类型有变化
- **15分**：情感性与信息性悬念各半（比例5:5左右），情绪拉扯感被信息披露稀释
- **10分**：大部分为信息性悬念（"他到底是谁"多于"他会不会背叛"），观众缺乏共情焦虑
- **0-9分**：结尾无明确Cliffhanger，或悬念与主线情节脱节（为钩而钩，强行切断）

## 维度二：节奏地图 (Pacing Map) - 25分

**检查动作：绘制全剧张力曲线（按3分钟/1集为刻度），标记Peak与Valley，统计连续塌陷区间数。**

- **25分**：波形完整（升-顶-降-升），无连续两段以上塌陷区（Valley持续不超过1段）
- **20分**：有一处塌陷区（连续2段低张力），但在塌陷区内埋有Sub-hook进行补救
- **15分**：有两处塌陷区，且无补救悬念，观众存在流失风险点
- **10分**：波形平坦，缺乏高低起伏，情绪无推拉，缺乏明确的Peak点
- **0-9分**：全程高张力（无喘息导致观众疲劳）或全程低张力（无爽点/痛点刺激），无节奏变化

## 维度三：Chemistry说服力 (Chemistry) - 25分

**检查动作：提取前3集的引力事件与阻力事件，确认内部阻力设定，标记信息差节点。**

- **25分**：前三集内阻力和引力均建立，有内部阻力层（如心魔/道德枷锁），存在观众比角色更着急的时刻（上帝视角信息差）
- **20分**：阻力和引力均建立但内部阻力薄弱（仅靠外部阻碍如家族/反派支撑，缺乏内生拉扯）
- **15分**：只有阻力或只有引力，缺一（单向奔赴或单向排斥，无Push-Pull张力）
- **10分**：Chemistry建立在三集之后，前3集CP感未锚定，留存受影响
- **0-9分**：无明确阻力或引力设计，角色关系沦为推动情节的工具

## 维度四：高燃场面 (Climax/High Stakes) - 25分

**检查动作：提取剧本中的规则/禁忌设定，核对高潮前角色试探底线的次数，判定高潮动作的主动/被动属性。**

- **25分**：有明确规则/禁忌建立，至少两次边界接近退缩（试探底线），角色主动打破规则（Active Choice）
- **20分**：有规则建立，一次边界接近退缩，角色主动打破规则
- **15分**：有规则建立但无边界接近铺垫，角色直接打破（爆发缺乏层次，突兀）
- **10分**：高燃场面存在但角色为被动接受（Reactive，如被陷害后自证，非主动破局）
- **0-9分**：无高燃场面，或高燃与前情节脱节（无铺垫的机械降神）

---

## 总分区间与评定

| 总分 | 评定等级 | 执行建议 |
| :--- | :--- | :--- |
| **90 - 100** | **优秀 (Greenlit)** | 核心机制完备，进入台词与视听细化阶段 |
| **75 - 89** | **良好 (Polish)** | 结构成立，针对失分维度进行局部场景替换或增设Sub-plot |
| **60 - 74** | **需要大改 (Restructure)** | 存在维度得分≤15，需从结构层重新排布Hook或重建角色阻力 |
| **0 - 59** | **重写 (Scrap)** | 两个及以上维度得分≤15，底层逻辑失效，优于修补 |

---

## 评分执行防偏指南

1. **证据驱动打分**：每项扣分必须对应具体的集数/场口/台词，禁止使用"感觉不够爽"等主观表述，必须替换为"第5集结尾缺情感性Hook"。
2. **屏蔽文笔干扰**：本量表只评估机制与结构，不评估辞藻华丽度。台词再烂，Hook在位即给分；文笔再好，节奏塌陷必扣分。
3. **阻断光环效应**：四个维度必须独立打分后再加总。不可因高燃场面极佳而放宽对钩子系统的评分标准。
4. **受众视角锚定**：张力与Chemistry的判定，需锚定目标受众的爽点/痛点体系，而非评审个人的审美偏好。评审需时刻自问："目标受众此时会划走吗？"而非"我喜欢这个桥段吗？"
