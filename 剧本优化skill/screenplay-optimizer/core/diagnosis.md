# 核心诊断流程 (core/diagnosis.md)

## 1. 诊断流程总览

诊断按以下四个步骤严格串行执行，前序步骤的输出直接作为后序步骤的输入：

1. **结构扫描**：将剧本拆解为集-段-场景单位，标记各基础单元的张力值与功能属性。
2. **四层诊断**：基于扫描数据，按 Hook → Rhythm → Chemistry → Peak 顺序逐层穿透。底层问题未解决前，暂缓上层诊断（例：Hook System失效时，Rhythm Map诊断无意义）。
3. **行动清单**：将所有诊断出的标记项按影响力排序，转化为具体的改写指令。
4. **输出**：按规范格式生成结构化诊断报告。

---

## 2. 四层诊断框架

### 第一层：钩子系统（Hook System）
执行标准与检查动作详见 `hook-patterns.md`。

### 第二层：节奏地图（Rhythm Map）
**标准波形（6-8段结构）**：
- 段1：钩子/悬念建立（高张力）
- 段2：信息/关系推进（中等）
- 段3：情绪积累（升）
- 段4：小高潮或转折（峰）
- 段5：余震/新悬念埋入（降但有钩）
- 段6：集尾钩子引爆（高张力）

**检查动作**：
对照波形，找出连续两段以上处于中低张力且无新悬念埋入的位置，标记为**【节奏塌陷区】**。

### 第三层：Chemistry说服力（Chemistry Persuasion）
**检查动作1**：
前三集内是否存在至少两次角色主动选择靠近对方的场景，若无则标记为**【chemistry建立不足】**。

**检查动作2**：
识别引力型信号（只有彼此才能感知的频率/默契），若前三集内无引力型信号，标记为**【chemistry缺少观众"比角色更着急"的驱动】**。

### 第四层：高燃场面结构（Peak Scene Structure）
**检查动作**：
找到剧本中标记为高燃的场景，向前追溯——是否存在明确的规则/禁忌建立？是否有至少两次角色接近这个边界但退缩？若高燃前铺垫少于两次边界接近，标记为**【高燃到达过早，期待值积累不足】**。

---

## 3. 欧美受众特殊检查

**检查动作1**：
每个主要角色行为动机检查，问"这个行为在没有外力推动的情况下角色自己会做吗"，若答案为否，标记为**【动机不足】**。

**检查动作2**：
类型标签匹配检查，对照 `Erotica` / `Dark Romance` / `Mafia` / `Enemies to Lovers` 标签，检查剧本是否具备该类型的核心元素，缺失则标记并给出补充方向。

---

## 4. 诊断输出格式规范

每一层诊断输出必须严格遵循以下四维结构：

- **评分**：0-25分（25分为该层满分，四层总计100分）
- **问题定位**：第X集第X段
- **问题描述**：直接引用对应的诊断标记（如：【节奏塌陷区】）
- **影响说明**：简述该问题对受众留存或情绪沉浸的破坏机制

**输出示例**：
```text
第二层：节奏地图（Rhythm Map）
- 评分：12/25
- 问题定位：第2集第3-4段
- 问题描述：【节奏塌陷区】
- 影响说明：连续两段仅做背景交代，张力持续处于中低位且无悬念埋入，导致第2集中段出现拖拽感，极易引发跳出。
```
